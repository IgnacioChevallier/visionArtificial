# TP3 Segmentación de tumores cerebrales con U-Net

Este trabajo práctico aborda **segmentación semántica binaria** en imágenes de resonancia magnética cerebral.

Se entrena una arquitectura **U-Net** sobre el dataset **[LGG MRI Segmentation](https://www.kaggle.com/datasets/mateuszbuda/lgg-mri-segmentation)** para separar región de tumor del resto del cerebro. 

Incluye exploración del dataset, preprocesamiento y aumento de datos, división train/val/test, entrenamiento y evaluación.
